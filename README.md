# Programação para Web 2

Repositório destinado às atividades, exercícios e projetos desenvolvidos na disciplina de **Programação para Web 2 (PWeb 2)**.

## Sobre a disciplina

A disciplina aborda o desenvolvimento de aplicações Web, explorando diferentes tecnologias, arquiteturas e formas de comunicação entre sistemas.

Ao longo das atividades, são trabalhados conceitos relacionados a:

- Desenvolvimento Web
- Arquitetura de aplicações
- Padrão MVC
- APIs REST
- Frontend e Backend
- Requisições HTTP
- JSON
- Banco de dados
- Integração entre aplicações
- Docker e Docker Compose
